## Findings to carry into every category

1. Map active Home summaries, owner list/add/edit/pins, public list/genre/modal, lifecycle and media consumers before coding. Retained exports or a passing isolated adapter do not prove the active UI uses the native API.
2. Round-trip zero, null, omitted and blank values and retained rich-text serialization. Manual fallback must expose initially empty optional inputs; search/provider failure must preserve drafts. Provider facts and creator overrides remain distinct.
3. Fence every async save continuation by account, generation, route and operation identity before and after awaits and before later mutations. Test noncooperative deferred resolution, parent reads, upload/import, and an abandoned finally while a newer operation runs. Retain original revision and same-intent retry keys.
4. Cancellation completes the caller before native resources necessarily settle. Preserve bounded transport/storage custody; prove explicit busy/retry recovery and eventual fresh-query success without stale append, unsafe lease release or limit increases.
5. Test actual pagination using page sizes, signed cursor responses, user scrolling/buttons and visible later rows. Account for observers racing manual clicks. A disabled/detached control is acceptable only when required completion is independently observed. HTTP200 alone does not prove visible results, and two pages do not imply complete results.
6. Exercise retained publication prompts and modal focus through actual UI decisions. Do not force clicks through overlays or bypass the user flow. Diagnose one failing scenario with source, trace and API evidence before another complete run.
7. Use compiled preview for acceptance with real guarded API/database/storage and bounded build output. Keep provider simulations distinct from live-provider qualification. Local focused selectors cannot produce a full protected qualification receipt.
8. Bind schema changes to committed SQL hashes, runtime privileges/readiness, producer fixture transitive imports, Docker context/COPY/ignore rules, documentation and proof fixtures. Verify clean root/backend/auth/frontend dependency owners; clear inherited Git metadata before test subprocesses and preserve unrelated scratch files.
9. Classify CI by exact commit, completed test identities and first assertions. Prior identical failures are evidence of unchanged observed failures, not proof that all causes are known or permission to waive required gates. Cancelled/skipped lanes remain incomplete.
